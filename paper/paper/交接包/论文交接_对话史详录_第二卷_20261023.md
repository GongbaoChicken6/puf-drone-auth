## 6. 原始提取物使用指南（`_tmp\convdigest\`）

| 文件 | 内容 | 用法 |
|---|---|---|
| sessions.json | 160 条会话元数据（=13 主对话 + 147 子代理；字段 id/createdAt/firstTime/lastTime/turns/preset/delegationDepth/titles） | 定位某段工作发生在哪个会话 |
| user_messages.jsonl | 1450 条用户侧消息（kind=user 447 条 = 主对话真人输入 297 + 子代理任务提示 150；字段 s/t/turn/kind/text，text 截断 700 字——约 34% 条目被截断） | 全文检索关键词（如 "ZC706"、"PYNQ"、"auto-review"）回放用户原话 |
| assistant_finals.jsonl | 570 条助手每轮最终回复（截断 900 字，约 67% 被截断） | 查当时给用户的结论性说明 |
| subagents.jsonl | 153 次子代理派发（child/label/时间） | 审查谱系核对 |
| todos.jsonl | 各会话 todo 快照 | 查任一时刻的任务清单状态 |

> 注意：提取物为截断版；需要完整原文时，用已落盘的零依赖解析脚本 `_tmp\convdigest\parse_sessions.mjs`（Node ≥22 即可运行，DSH 自带 Node 24 满足）：
> ```
> node _tmp\convdigest\parse_sessions.mjs "C:\Users\<user>\.dsh\sessions\--D-~6587~4EF6-ssssssss-FPGA--\<会话id>" > 完整原文.jsonl
> ```
> 脚本自动逐帧解压多帧 zstd 并拼接成 JSONL。也可以直接让任意 DSH 对话代查。
> 字段补充：t 为 UTC Unix 毫秒时间戳（+8 小时=北京时间，对应 §2 引语的 [MM-DD HH:mm]）；s 带 session- 前缀，与 §1 表短 id 按前缀匹配；查会话跨度用 sessions.json 的 firstTime/lastTime（createdAt 是会话创建时间，可能与首次干活时间相差很远，如 0674ca76 创建于 9-26、实际干活从 10-06 开始）。
