## 1. dataviz skill 规则摘要（已学，静态论文图适配版）

技能完整流程七步：选形式 → 按职责配色 → 跑验证器（不目测）→ 标记规格 → 交互层 → 无障碍 → 渲染后人工检查。其中"交互层/暗色模式"两条是 Web 语境，论文静态图按 §2 替换为打印适配。

### 1.1 选形式速查（论文会用到的行）

| 数据的任务 | 形式 | 备注 |
|---|---|---|
| 比大小（少量类目） | 条形图（横向，类目名长时） | 单序列→**一色**（slot1），不按值渐变 |
| 随时间变化 | 折线；单序列可加 10% 透明度面积 | 网格实线细灰，**禁虚线网格** |
| 区分多序列（≤3） | 分组条形/多折线 | ≥2 系列必须有图例；≤4 系列加直接标注 |
| 一个系列是主角、其余是背景 | **强调式**：主角 slot1、其余灰 | "提升了 X"类故事一律用这个，别开彩虹 |
| 大于/小于基线 | 发散条形（蓝↔红，灰中点） | 双臂等步数 |
| 前后对比（逐项） | 哑铃图 | 优化前后对比若做成图用它；**本文按指南做成表** |
| >7 个类目都要看 | **表格**（或表+图） | 威胁-对策、资源表正是如此——不是图 |
| 单个数字 | 大字数字，不画一根条的"图" | 摘要页/关键指标可用 |

### 1.2 颜色四职责（核心纪律）

- **类别色=身份**（这是哪个系列），按固定槽序用，**永不循环生成第 9 色**；单序列所有条同色，禁止按数值深浅着色。
- **顺序色=量级**：单色相由浅到深（本文热图/密度图用蓝渐变，见 §3）。
- **发散色=极性**：两暖冷色相+灰中点（蓝↔红），中点不得有色相。
- **状态色（好/警/严/危）只留给"好坏"语义**，不当第 4 个系列色用。
- **文字不用系列色**：标注、图例、轴文字用墨色（黑/深灰/浅灰三级），身份由旁边的色点/色块承担。

### 1.3 验证器（本文调色板已实测）

```bash
node <skill目录>/scripts/validate_palette.js "#2a78d6,#eb6834,#1baf7a,#eda100,#e87ba4,#008300,#6250d6,#e34948" --mode light
```

**2026-10-24 实测结果：ALL CHECKS PASS**（亮度带/彩度下限/CVD 相邻对 ΔE 9.1/普通视觉下限 19.6 全过；WARN 仅 3 个浅色槽对白底对比 <3:1 → 补偿规则：这些颜色上必须带直接标注或数值表）。前 3 槽加严 `--pairs all` 也 PASS（最差对 9.2）——**散点/小倍数图系列数上限 3，其余形式上限 8，本文实际最多用到 3~4 个系列**。

### 1.4 标记规格（换算到 matplotlib）

| 技能规格（Web px） | 论文图参数 |
|---|---|
| 线宽 2px、圆角连接 | `linewidth≈1.6~2.0`（pt），solid_capstyle='round' |
| 标记点 ≥8px+2px 白环 | `markersize≥5`，`markeredgecolor='white'`, `markeredgewidth≈0.8` |
| 条形 ≤24px、贴基线端直角 | 条宽≤0.6 倍带距；不用花哨圆角（印刷小图看不清） |
| 堆叠/相邻填充间 2px 表面缝隙 | 条形 `edgecolor='white', linewidth≈1.2` |
| 网格：实线、发丝、比底色深一档 | `grid(color='#e1e0d9', lw=0.6, ls='-')`，置底层 |
| 直接标注只标端点/极值/主角 | **禁止每个数据点都标数**（反模式） |
| 单序列无图例框 | 标题即说明；≥2 系列必须图例 |

### 1.5 反模式自查表（每张图交稿前过一遍）

1. **双 Y 轴**——绝对禁止（技能称其为头号错误）；两个量纲→两张小图或归一化。
2. 彩虹/多色相做量级渐变；发散中点带色相；蓝↔青做两极。
3. 类目无序却按值深浅着色（双编码）。
4. 每点标数、虚线网格、粗饱和大色块、给标记描边（应改白缝隙/白环）。
5. 饼图比较接近的值；2 片饼；单条条形图。
6. 生成第 9 个系列色；系列数超上限不折叠成"其他"。
7. 文字穿系列色；标签被裁切/溢出。
8. 图例缺失（≥2 系列）或单系列硬放图例框。

## 2. 静态论文图的打印适配（替换技能的 Web 规则）

- **无 hover/tooltip** → 每个结论数值必须直接可读：轴刻度+选择性直接标注；细节数值允许留在正文表格里（表格即"table view 孪生"）。
- **只做浅色模式**（白底 #fcfcfb/纯白），验证器只跑 `--mode light`。
- **灰度打印风险**（评审可能黑白打印）：系列 ≤3；**颜色之外必须有第二编码**——不同 marker 形状（o/s/^）或线型（实线/虚线*仅用于线型语义*），关键系列直接标注。技能的 texture 是打印场景的正解，matplotlib 里即 hatch（45° 方向 `hatch='///'`），仅黑白失效时用。
- 尺寸按**单栏 3.5 in / 双栏 7.16 in**（IEEE 模板）设计，字号成品后 ≥7pt 可读；矢量优先（PDF/SVG），位图 300 dpi。

## 4. 数据图管线：matplotlib + SciencePlots

**SciencePlots**（github.com/garrettj403/SciencePlots）：pip 安装的 matplotlib 样式包，`science`/`ieee`/`nature` 等 .mplstyle，天生白底细网格衬线小字号，黑白打印安全，与上面调色板叠加即"IEEE 版式 + 已验证配色"。

```bash
pip install SciencePlots   # 无 LaTeX 环境用 no-latex
```

**统一模板**（存 `paper/figures/src/_style.py`，各图 import）：

```python
import matplotlib.pyplot as plt
import scienceplots  # noqa

PAL = {'c1': '#2a78d6', 'c2': '#eb6834', 'c3': '#1baf7a',
       'mute': '#898781', 'grid': '#e1e0d9'}

plt.style.use(['science', 'ieee', 'no-latex'])   # 有 LaTeX 时去掉 no-latex
plt.rcParams.update({
    'font.family': 'serif',
    'font.serif': ['SimSun', 'Times New Roman'],  # 中文宋体+西文衬线；强调处 SimHei
    'axes.unicode_minus': False,
    'grid.color': PAL['grid'], 'grid.linewidth': 0.6, 'grid.linestyle': '-',
    'axes.prop_cycle': plt.cycler(color=[PAL['c1'], PAL['c2'], PAL['c3']]),
})
# 单栏 fig, ax = plt.subplots(figsize=(3.5, 2.4))；双栏 (7.16, 3.2)
# 导出：fig.savefig('fig3-1_lr_attack.pdf') + ('...png', dpi=300)
```

**数据纪律（红线）**：脚本只从仓库文件读数（JSON/RPT/生成器输出），**禁止在 .py 里手写 metrics 数值**；引用处按第一卷四级口径标注（STATIC/LIVE/MODEL/待板）。ML 两图重绘时源数据取 `data/ml_attack/` 原始结果文件，PNG 仅作对照。

**HTML 排版纪律**（§1/§2 打印适配落到 CSS，模板已内置）：

- 白底纯色；无阴影、无渐变、无透明叠加；框线 1.5~2px 墨色、圆角 ≤6px
- 填充只用浅色调（`--tint1` #cde2fb 档）+ 墨色文字；**文字永不用系列色**；标题 SimHei、正文 SimSun、代码/信号名 Consolas
- flex/grid 手排，框位与间距全部人工可控——这正是换掉自动布局的原因
- 连线横平竖直、箭头统一规格（模板 `.arrow`：56×2px 线 + 12px 实心三角头）；跨行折线用绝对定位 SVG 覆盖层
- 图内不放图题（题注在 Word 加）；口径标注（STATIC/LIVE/MODEL/待板）固定图内右下角 `--ink3` 小字
- 交稿前同样过 §1.5 反模式清单 + 灰度检查（PIL `convert('L')` 目检一次）

**时序图专用做法**（六帧协议★）：模板内 `.seq` 栅格雏形——participant 列头（浅蓝带）+ 每帧一行，六帧密度、挑战/响应高亮、字段标注全部手工可控，优于 `sequenceDiagram` 自动布局。
