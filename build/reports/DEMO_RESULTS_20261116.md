## 三、已知限制（演示时避开）

- **板A 的应答帧被物理层截断**：CHALLENGE 44B 正常收到，但 RESPONSE 只回 36/44 字节（稳定复现6次，CRC证明尾部丢失）→ 无法做"真指纹比对后判REJECT"
- 所以板A的拒绝走"未注册机器"路径（无模板→直接REJECT），不从PUF比对出
- 板A的HC-12现由CH340 5V供电（原先充电宝供电导致不共地、完全不通）

## 四、现场演示操作顺序

**准备（我来做）**：烧双板bit → 起桥 → 断言密钥 → 自检模板/池 → 打开页面

**演示（你来点）**：
1. 板A：SW13 → SW7，板B：SW13 → SW7  （两台先后发起，弹窗应出现2条）
2. 弹窗里点 **Board A 的"选择/接入"** → 红色 **REJECT** + 拒绝动画（陌生机器）
3. 弹窗里点 **Board B 的"选择/接入"** → 绿色 **PASS** + 激光（合法机器）
4. 板B 通过后可在页面控制马达（步骤③）

**注意**：每次重新发起认证前先按 **SW13**（复位到空闲态）；断电后 bit 丢失，需我重新烧写。
