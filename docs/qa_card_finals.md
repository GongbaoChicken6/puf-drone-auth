# 决赛答辩 Q&A 手卡（2026-11-13 版）

## 一、9 问标准口径

### Q1 后续通信被破译？
> 本协议是接入认证协议，认证后业务流量的保护走"会话密钥 = Speck(K, C2)"扩展——密码原语双侧已具备（RTL Speck 核 + Python speck.py），每轮认证产生新鲜 C2 保证会话密钥不重复。这是已规划的下一步，不在本届范围内。

### Q2 伪基站能否劫持？
> 密码学上不能。终端用 R2=Speck(K,C2) 逐字节验证基站身份——伪基站没有 K 就编不出正确 R2。仿真与测试台已完整验证此链路（TB 端到端 + 攻击工具 --simulate 排练模式），板上按剧本彩排复验。DoS（信道拥塞）无法防，但我们会主动告知（信道 IDS 检测噪声洪泛）。另：Tier2 ALARM 帧带 MAC，伪基站连告警都无法伪造——MAC 计算已实现但按排期押后上板。

### Q3 大信号灯有必要吗？
> 有。决赛场地 3-5 米外看不清 5mm LED。我们外接 10mm LED + 蜂鸣器到 PMOD J58，灯语模式：PASS 绿闪 3 次后常亮+两短哔、REJECT 红交替闪+长鸣、BLOCKED 双亮+双长哔。已集成到 RTL 并通过 CI 回归。

### Q4 迁移到其他板？
> 本项目自身就是 ZC702→ZC706 迁移实例（两版 wrapper 并存）。协议/密码/PUF 核心是参数化纯 RTL，迁移=改 wrapper/引脚约束+重建+重注册，约 2-3 天。seed2 布局变体证明"一机一布局"防克隆流程可复制。

### Q5 厂商使用方便吗？
> 终端侧一个 RTL 模块，对外接口只有 UART + 认证按键 + LED——厂商例化即用，资源 2% LUT。站侧 Python 包分层清晰（protocol/enroll/hsm/pool/threshold + REST/SSE）。有完整字节级协议契约文档+黄金向量+CI 门禁，交付文档见 docs/integration_guide.md。

### Q6 通信距离？
> 演示用 HC-12 无线模块（手册百米级，室内实测桌面距离全通）。系统对链路透明——终端只见 UART，换更大功率数传电台零改协议/RTL。

### Q7 协议完整性？
> 本协议定位接入认证，覆盖：五帧双向鉴别+灰区加测+CRC 容错+重放窗+BLOCKED 状态机+挑战池一次性消费。业务数据保护走会话密钥扩展（同 Q1）。帧格式兼容 MAVLink v2（0xFD 头+CRC_EXTRA），可直接嵌入 MAVLink 生态。

### Q8 前端展示效果？
> Three.js 3D 舞台 + 帧结构查看器（逐字节分段着色+中文字段注记+密文锁标）+ 帧飞行动画（终端↔基站数据流具象化）+ 无人机 HUD（人工姿态仪/高度/航向）。全部离线自包含。

### Q9 ARM 内核（PS）用起来了吗？可以用 ARM 控电机吗？
> 没用，是刻意的设计选择而非遗漏：Zynq 只用 PL 侧——PUF 环振阵列、五帧协议状态机、Speck 密码核、UART 收发共 17 个模块全部纯 RTL 实现。安全论证：信任根 100% 硬件化，无 OS/无驱动/无软件栈 = 没有可注入的软件攻击面，认证路径时延确定可测。ARM 双核预留为扩展位（规划：上 PetaLinux 跑基站侧协议栈/网关）。电机方面：控制信号难题的本质是**电气电平匹配**（FPGA 与 ARM 的 IO 输出到 J58 都经同一电平域，均为 3.3V，而 L9110 在 5V 供电下阈值 3.5V）——换 ARM 控制同样是 3.3V，不解决根因，需的是电气层方案（降压供电或换阈值固定的驱动芯片）。竞赛周期内不引入 FSBL/裸机软件栈是风险控制决策。

## 二、诚实边界（评委必问）

### 密钥形态
> 当前演示用预置 K（注册时装入站端 HSM 模拟），PUF 派生密钥路径已实现并仿真验证（KDF 冻结、黄金向量、CI 门禁），板上启用需 0x0096 注册通道 + K_boot 纠错。有效熵 ≈44bit。我们不声明板上已达成 PUF 派生密钥——这是诚实的边界声明。

### DoS
> 任何认证协议都无法阻止信道拥塞。我们把拥塞显式暴露为信道 IDS 告警（channel.noise）而非静默。

### 会话加密
> 未实装。密码原语双侧已具备（这是可验证的事实），路线图明确。

## 三、新功能解说要点

### 巡检（AUTH_POLL 0x0097）
> 基站可主动巡检任意终端——点击网页巡检按钮，板端等效按下认证键，发起完整五帧双向认证。协议第 7 条消息，TX/RX 双侧 id_legal+CRC_EXTRA 全同步。

### 伪基站攻击（三重证据）
> 攻击脚本抢在真基站前注入伪 RESULT → 终端 R2 失配 → ① 信道 IDS 红色横幅 ② CONFIRM_FAIL 上行告警 ③ 站端矛盾关联告警——三重证据同屏。

### 无人机演示
> PASS 解锁起飞→航点飞行→返航降落；REJECT 自动返航。3D 舞台实时跟踪飞行姿态。
