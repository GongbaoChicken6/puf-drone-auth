## 读完这一篇，你能做到

1. 独立完成 ZC706 的开箱检查、第一次上电和灯序自检；
2. 装好 Vivado 烧录驱动，把本项目的比特流烧进板子并确认 DONE/心跳灯正常；
3. 会用拨码（SW12）给两块板分别设终端 ID、用按键（SW7/SW13）操作；
4. 把 PMOD 的 UART 接到 USB-TTL，和 PC 串口助手互通（自环测试）；
5. 遇到常见故障能按速查表自己定位（90% 的问题都在这张表里）。

> 建议节奏：**第 1 天上电自检 + 烧写 + 心跳**（约 2~3 小时）；**第 2 天拨码/按键 + UART**（约半天）；
> 之后按迁移计划的 Phase 7/8 进入 PC 联调与注册。

## 1. 开箱与「验明正身」（新板第一件事）

### 1.1 核对板型

- 看板上丝印/包装：应为 **ZC706 Evaluation Board**，核心芯片是 **XC7Z045-2FFG900C**（UG954 p.7 的器件描述）。
- 确认不是 ZC702（ZC702 芯片是 XC7Z020、CLG484 封装）——两块板外观差别很大，ZC706 更大、带 FMC HPC 大连接器。

### 1.2 检查配件（以实物为准）

- **12V 电源适配器**（套件标配，UG954 p.65「universal 12V power supply」；AR#67507 记 12V/5A）。
- **USB 线**：A 口转 **Micro-B**（JTAG 用）；套件若含 Mini-B 线，用于板载 USB-UART（本项目用不到）。
- **ATX 4-pin 转接缆**（Xilinx PN 2600304，套件部分版本附带，用于从电脑 ATX 电源供电——**只在没有适配器时按 UG954 Figure 1-30 使用**）。
- 快速入门指南/SD 卡等（以实物为准）。

### 1.3 核对默认开关/跳线（UG954 **Appendix A** Table A-1/A-2）

新板出厂默认（上电前逐项核对，不一致就先恢复）：

| 器件 | 默认状态 | 说明 |
|---|---|---|
| SW1 | OFF | 电源关 |
| SW4 | **10**（指向 J3 排针） | 用 USB JTAG 前必须改 **01** |
| SW11 | **00000**（全下） | JTAG 启动模式 |
| SW12 | 全 OFF | 用户拨码，读 0 |
| J18 | **有跳线（1-2）** | FMC/PL 的 VADJ=2.5V 上电使能，**保持默认** |
| J66 | **空（OPEN）** | PL 电源上电使能，**保持为空** |

> 判读方法：拨码开关上印有 **ON** 字样的一侧为「1」，另一侧为「0」；SW4 的 2 位从红点/1 号位开始数。
> 不确定方向也没关系——**拨错不会损坏板子**，只是 JTAG 找不到设备，两个方向各试一次即可。

## 2. 安全须知（红线 3 条，先读再做）

1. **电源**：只用 **12V** 适配器插 **J22**。⚠ **绝对不要**把电脑 ATX 电源的 **6 针**插进 J22——UG954 p.65 原文警告：ATX 6 针与 J22 引脚定义不同，**插上会损坏板卡且失保**。若只有 ATX 电源，只能用套件的 **4 针转接缆（PN 2600304）**（UG954 Figure 1-30）。
2. **ESD**：UG954「Discharge Caution」——拿板前先摸接地的金属机壳放电或戴防静电腕带，**绝不在铺地毯/化纤桌面**上直接操作。
3. **带电不插拔**：PMOD/FMC/USB 线尽量在断电时插拔；不要乱动 **J18/J66** 默认状态（J66 插跳线会让 PL 侧电源上电时不起，见 UG954 p.82）。

## 3. 认识板卡（10 分钟，对照 UG954 Figure 1-3 的编号找位置）

### 3.1 灯（Table 1-27，全部绿灯为主）

| 灯 | 名称 | 含义 |
|---|---|---|
| DS22 | VCC12_P | **12V 输入到位** |
| DS24 | CTRL1_PWRGOOD | 电源控制器各路输出正常（**板子健康的综合指示灯**） |
| DS15 | VADJ_FPGA | VADJ（PL 的 2.5V 域）正常 |
| DS16 | VCC3V3_FPGA | 3.3V 正常 |
| DS11 | VCCINT | 内核 1.0V 正常 |
| DS13 | VCC1V5_PL | PL 1.5V 正常 |
| DS23 | FMC PG | FMC 电源好（不插 FMC 卡时无意义） |
| DS1 | POR（红） | 系统复位中（上电瞬间闪一下正常） |
| DS2 | FPGA_INIT_B（红/绿） | 红=FPGA 初始化中；**绿=初始化完成** |
| DS3 | **DONE**（绿） | **比特流加载完成**——烧写成功就看它 |
| DS8/DS9/DS10 | GPIO_LED LEFT/CENTER/RIGHT | 用户灯（本设计：结果码，高电平亮） |
| DS35 | GPIO_LED_0 | 用户灯（本设计：心跳，~0.75Hz） |

### 3.2 开关、按键、拨码

| 器件 | 丝印/位置 | 作用 |
|---|---|---|
| SW1 | 电源滑开关 | ON/OFF 总电源 |
| SW4 | 2 位拨码（JTAG 选择） | 10=J3 排针（默认）、**01=U30 板载 USB JTAG（我们要的）**、11=J62 排针（UG954 p.34） |
| SW11 | 5 位拨码 | PS 启动模式；**00000=JTAG（默认）**、00010=QSPI、00110=SD（UG954 Table 1-2） |
| SW12 | 4 位拨码（用户） | **ON=1/OFF=0**；板内 4.7k 下拉；对应 terminal_id 低 4 位（Table 1-30） |
| SW7/8/9 | 三个用户按键 LEFT/CENTER/RIGHT | 本设计用 **SW7=认证启动键**（Table 1-29） |
| SW13 | **CPU_RESET** 按键 | 复位（按下=0，低有效） |
| SW10 | **PROG_B** 按键 | 按下清空 FPGA 配置（DONE 灭）——**联调时别误按** |

### 3.3 接口

| 接口 | 位置 | 用途 |
|---|---|---|
| **J22** | 板边 6 针 Mini-Fit | 12V 电源输入 |
| **U30（Micro-B）** | 面板丝印「JTAG」 | **烧录用**（Digilent USB-JTAG，UG954 p.33） |
| **J21（Mini-B）** | 板边 | 板载 USB-UART（Silicon Labs CP2103GM）——**只连 PS 芯片，PL 用不了**（UG954 p.51） |
| J2（Micro-B） | 板边 | PS USB 2.0 OTG（与我们无关） |
| **J58（PMOD2）** | 2×6 排针 | **本项目 UART 引出**（经 TXS0108E 电平移位，UG954 p.62-64） |
| J57（PMOD1） | 2×6 排针 | 走 I2C 扩展芯片（TCA6416），**不能当 UART 用**（UG954 p.62-64） |
| J37 / J5 | 大连接器 | FMC HPC / LPC（本项目不用） |

> 提醒：**面板上有 3 个 USB 口**（JTAG、UART、USB OTG），丝印不同。认准 **「JTAG」** 那个插烧录线；
> 插错不会烧板，但 Hardware Manager 会找不到芯片。

## 4. 第一次上电（不接电脑，裸板自检）

### 4.1 步骤

1. 确认 SW1=OFF、**不插**任何 FMC/PMOD 外设、不接 USB 线。
2. 把 **12V 适配器**插进 **J22**（对准缺口插紧，听到/感到卡扣即可）。
3. 把 **SW1 拨到 ON**。
4. 观察灯序（见 4.2）。

### 4.2 预期灯序（上电后 10 秒内）

| 时间 | 应该看到 |
|---|---|
| 立即 | **DS22 亮**（12V 到位）；DS1 POR 红色闪一下 |
| +1 秒 | DS24、DS15、DS16、DS11、DS13 相继变绿（各路电源正常） |
| +5 秒 | DS2 INIT **由红转绿**（FPGA 初始化完成） |
| 全程 | **DS3 DONE 保持灭**——还没烧写比特流，正常 |

> 只要 **DS22 + DS24 全亮**，板子的电源系统就是健康的。

### 4.3 关机

SW1 拨回 OFF → 等 5 秒 → 拔适配器。

### 4.4 上电失败排查（先别反复插拔）

- DS22 不亮：适配器/线接触不良 → 插紧重试；换一个插座。
- DS22 亮但 DS24 不亮：电源系统异常——先断电重启一次、清空负载（不插任何外设）；仍不亮 = 硬件问题，报告老师（参考 ZC702 的前车之鉴：PWRGOOD 不亮就是板内电源没起来）。

## 6. JTAG 连线与烧写比特流

### 6.1 板端设置（一次设置，之后不用动）

1. **SW4 拨成 01**：1 号位 OFF、2 号位 ON（默认 10 指向 J3 排针，USB JTAG 会认不到——这是最常见的「找不到设备」原因）。
   实物判读：开关丝印 **ON 在右侧、箭头朝右**，拨杆沿水平方向滑动 ⇒ **朝右=1、朝左=0**；即 **1 号拨杆朝左、2 号拨杆朝右**（1/2 号看开关旁旋转的小字）。拨错不会损坏板子，认不到就两根一起反过来。
   官方定义（UG954 Table 1-11 注 1）：**0 = open（断开）、1 = closed（闭合/ON）**；Table A-1：出厂默认 **10 = J3 排针**（所以新板必须改）。
2. **SW11 保持 00000**（全 OFF，JTAG 启动，出厂默认）。
3. 板子接 12V、SW1=ON。
4. Micro-B 线插面板 **「JTAG」** 口，另一端接电脑。

### 6.2 GUI 烧写（Vivado Hardware Manager，英文按钮原文，照点即可）

1. 打开 Vivado → 左侧 **Flow Navigator** 底部点 **Open Hardware Manager**。
2. 上方绿条点 **Open Target** → **Auto Connect**。
3. 左侧 **Hardware** 面板出现：`localhost:3121` → 目标 → **xc7z045_0**（这就是芯片）。
4. 右键 **xc7z045_0** → **Program Device...** → **Bitstream file** 选：

```text
D:\puf-drone-auth\build\board_zc706\w3_top_zc706.bit
```

5. 点 **Program**。进度条走完、底部出现完成日志即成功。

### 6.3 烧写成功后的现象（验收点）

| 现象 | 说明 |
|---|---|
| **DS3（DONE）变绿** | 比特流加载成功——**最重要的成功标志** |
| **DS35 以约 0.75Hz 闪烁** | 心跳灯（本设计用 A17=DS35；1.5V bank 驱动，**偏暗是正常现象**） |
| DS2 INIT 绿 | 配置正常 |
| DS8/DS9/DS10 灭 | 空闲态（还没认证） |

> 心跳闪 = 时钟（200MHz 差分→MMCM→100MHz）、复位、约束全链路 OK——这是上板自检的「绿灯信号」。
> 心跳**不**闪：先查 DS15（VADJ）、J18 跳线、SW4/SW11，再查是否烧错 bit 文件。

### 6.4 命令行烧写（可选，双板/批量时更省事）

本仓库已备好带防御的烧写脚本（自动校验器件型号、多板时要求传序列号）：

```bat
D:\vivado\2026.1\Vivado\bin\vivado.bat -mode batch ^
  -source D:\puf-drone-auth\build\tcl\program_zc706.tcl ^
  -tclargs D:\puf-drone-auth\build\board_zc706\w3_top_zc706.bit
```

两板同接一台电脑时，第二个参数传序列号（看 Hardware Manager 里 `Digilent/<序列号>` 一段）。

### 6.5 关于「断电丢失」——新手最容易困惑的一点

- 本板 **SW11=00000（JTAG 启动）**：比特流是烧进 FPGA 的**易失配置**（SRAM），**断电即丢失**。
- 所以：**每次重新上电都要重新烧写一次**。演示当天不要中途断电；要断电就把「上电→烧写」写进流程单。
- 若要「上电自动加载」（固化到 QSPI Flash），需要改 SW11=00010 并用 Vivado 写 Flash（UG954 Table 1-2 + UG470）——**当前阶段不做，避免多一个变量**。

## 7. 烧写后自检清单（5 分钟，逐项打勾）

- [ ] DS3 DONE 绿；DS2 INIT 绿；DS22/DS24/DS15/DS16/DS11/DS13 绿。
- [ ] **DS35 心跳闪烁**（凑近看，偏暗正常）。
- [ ] 拨码 **SW12**：本设计 **ON=1**。板 A 只把 **1 号位**拨 ON（=0001=ID1）；板 B 只把 **2 号位**拨 ON（=0010=ID2）。
- [ ] 拨完拨码后按一下 **SW13 复位**，让设计以新 ID 重新开始。
- [ ] 按一下 **SW7（LEFT）再松开**：DS9（busy，偏暗）亮 → DS8/DS10 给出结果码（01=通过：DS8 亮）。
- [ ] **不要按 SW10（PROG_B）**——按一下会把配置清空（DONE 灭），要重新烧写。

> 说明：DS9/DS35 位于 1.5V 电源域，驱动板上 NDS331 三极管时电流偏小，**亮度明显低于 DS8/DS10 是设计已知特性**；
> 结果码特意放在 2.5V 域的 DS8/DS10 上，就是为了演示时看得清。

## 8. UART 接线（PMOD J58 → USB-TTL，PC 联调用）

板载 USB-UART（J21）只连 PS 侧，**PL 用不了**。本项目的 PL UART 从 **PMOD J58** 引出
（板上有 **TXS0108E(U40)** 做 3.3V↔VADJ(2.5V) 电平移位，所以 **USB-TTL 用 3.3V 逻辑直连即可，不需要分压电阻**）。

### 8.1 引脚（UG954 Table 1-31，已与项目 XDC 逐脚核对）

| J58 针脚 | FPGA 引脚 | 信号 | 接 USB-TTL 的 |
|---|---|---|---|
| **pin 1** | AJ21（PMOD1_0） | **radio_txd（板→PC）** | **USB-TTL 的 RX** |
| **pin 5** | AB21（PMOD1_2） | **radio_rxd（PC→板）** | **USB-TTL 的 TX** |
| pin 9~12 中的一个 | — | GND | **USB-TTL 的 GND** |
| — | — | — | USB-TTL 的 **VCC 不接** |

> GND 具体是 9/10/11/12 哪一脚：用万用表「通断档」测它与板上任意 GND（如 J22 外壳金属片）是否相通——通了就是它。
> UG954 只在 Figure 1-29 给出了 GND 排布，没有逐脚文字表，所以**以万用表实测为准**。

### 8.2 接线（3 根线，交叉接）

```text
USB-TTL TX  ──────────────  J58 pin 5（板 RX）
USB-TTL RX  ──────────────  J58 pin 1（板 TX）
USB-TTL GND ──────────────  J58 任一 GND 脚
USB-TTL VCC  ─── 不接 ───
```

⚠ 两个坑：

1. **USB-TTL 模块必须是 3.3V 逻辑**：接线前用万用表量模块 TX 空闲电平，应为 **3.3V**（市售 CH340 有 5V 版/跳线版，5V 直连会顶到 PMOD 的 3.3V 侧）。
2. **别插 J57**：它走 I2C 扩展芯片，不是 UART（UG954 p.62-64）；UART 只在 **J58** 上。

### 8.3 自环预检（先证明 PL 的 UART 通路活着）

1. 用一根杜邦线**短接 J58 pin1 ↔ pin5**（TX 短到 RX）。
2. PC 打开串口助手（如 Tera Term / SSCOM），选 USB-TTL 的 COM 口，**115200 8N1**，发送任意字节。
3. **看到原样回显 = TXS0108E 与 PL UART 通路 OK**。拆掉短接线，进入联调。
（此步需要 FPGA 已烧写本设计——回显由 PL 侧 UART 完成。）

### 8.4 PC 端软件（项目联调用，迁移计划 Phase 7 详述）

```bat
pip install pyserial
python -m src.python.server.main --port COMx --baud 115200
```

## 9. 双板编排（本项目终端 1/2）

1. 板 A：SW12=**0001**（ID1）；板 B：SW12=**0010**（ID2）。
2. 每板一根 USB-TTL → PC 两个 COM 口；**给 COM 口贴标签**（COM3=A、COM4=B），联调时别搞混。
3. JTAG 烧写：**逐块上电烧写最稳**（一次只开一块板）；或两块同时接，用 program_zc706.tcl 传序列号区分。
4. 两块板都烧好后，演示期间保持供电（断电需重新烧写）。

## 10. 故障速查表（现象 → 原因 → 处理）

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| 上电没灯 | 适配器没插紧/插座没电 | 重插 J22，换插座；别反复拔插板子 |
| DS22 亮、DS24 不亮 | 电源系统异常 | 断电重启清负载；仍不亮报硬件故障 |
| Hardware Manager **Auto Connect 找不到设备** | ① SW4 不是 01 ② 驱动 ③ 线 ④ 板没上电 ⑤ 插错 USB 口 | 按 ①→②→③ 顺序查；SW4 两个方向各试一次 |
| 烧写报错/失败 | 板未上电、JTAG 线松、bit 文件不匹配 | 确认板已上电、线插紧、bit 是 `w3_top_zc706.bit` |
| 烧写成功但 **DONE 不亮** | DS2 红=配置中；SW10 误按；bit 不对 | 等几秒看 DS2 转绿；重烧 |
| DONE 亮但 **心跳不闪** | 时钟/复位问题 | 查 DS15（VADJ）→ J18 跳线 → SW4/SW11 → 重烧 |
| 心跳闪但按键无反应 | 按法不对 | SW7 **按一下再松开**（设计按上升沿触发）；确认 SW13 没被按住 |
| 拨了 ID 但结果不对 | 拨码方向反/没复位 | ON=1；改拨码后按 SW13；万用表量 AB17/AC16/AC17/AJ13 电平 |
| 串口无回显 | TX/RX 接反、没共地、模块 5V、误插 J57 | 先做 8.3 自环测试；万用表测电平 |
| DS9/DS35 很暗 | 1.5V 域驱动三极管电流小（已知特性） | 正常现象，看结果码请认 DS8/DS10 |
| 板子发烫/异味 | 电源异常 | 立即断电，报告老师 |
