# 02 · 板上实验数据与分析（全部【板上实测】，2026-11-02 收官）

## 1. 背景叙事：一次真实的"克隆攻击→根因→修复→验证"闭环（建议写成案例）

1. **攻击得手**：11-01 假冒实验发现，两块同型号板烧**同一份生产 bit** 后指纹完全相同（跨板 HD 仅 0~1，本应 ~128/256）——"复制比特流"这种最朴素的克隆攻击在当时配置下真实生效（data/d1_evidence/1101_假冒实验_双板均PASS_唯一性存疑.log）。
2. **三路根因调查**（服务器审计/RTL 数据流追踪/仿真注入，报告在 data/d1_evidence/rootcause/）：响应位 = 两环计数的**大小比较**（只保留排序），16 环是 RTL 复制体，排序由**布局布线**决定——同 bit ⇒ 同布局 ⇒ 同排序 ⇒ 同指纹。H1"没测硅"与 H3"服务器 bug"均被排除：环振计数真实进入响应（线上 1~4bit 物理漂移），HD 比对逐比特复核吻合。
3. **修复**：为第二块板构建**布局差异化** bit（PBlock 强制 16 环迁入 X1Y0 时钟区域，与生产布局 X1Y4/5 零站点重叠；WNS +1.213ns；seed2 SHA256 见日志）——"每设备唯一布局配置"成为唯一性来源（与文献中 FPGA PUF 布局主导熵的公理一致，对照分析见 docs/PUF_ARTY_S7_reference_comparison_20261102.md）。
4. **板上验证**：下述全部数据。

## 6. 模板与守卫

- tid=1 / tid=2 各 100 CRP，64/64 位 3 次重复测量全稳定（100%）
- tid=2 两两 HD：min 17 / median 32 / mean 32.1 / max 46（非退化）
- **阶序守卫首战**：注册 tid=2 时对 tid=1 的 Kendall 阶序一致度 0.433 < 0.85 阈值 → 放行为独立设备（克隆模板会被拒收，防线在服务器侧）
- M1 指标：uniformity 0.4873（理想 0.5）、reliability 代理 1.0；M2 SAC 雪崩全局 0.3807（数据在 data/d1_evidence/puf_metrics_1102.json、puf_sac_1102.json）
