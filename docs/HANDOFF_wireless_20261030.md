## 模块分配表（已在模块背面用记号笔标注）

| 标记 | 信道 | 波特率 | 接哪里 | 配对模块 |
|------|------|--------|--------|----------|
| **A板** | C001 | 115200 | 板 A 的 J58（pin1/pin5/pin9 三根线） | A-PC |
| **A-PC** | C001 | 115200 | PC 的 LinkE 适配器（COM6） | A板 |
| **B** | C006 | 115200 | 板 B 的 J58（pin1/pin5/pin9 三根线） | B-PC |
| **B-PC** | C006 | 115200 | PC 的 CH340 适配器（COM11） | B |

- 模式统一 FU3（透传）；两对信道错开 5（C001↔C006），互不串台。
- **SET 引脚悬空**（出厂透传即用；只有重新配置时才接 GND 进 AT 模式）。

## J58 接线（板侧三根线）

```
模块 RXD ← J58 pin1（板 TX）
模块 TXD → J58 pin5（板 RX）
模块 GND ← J58 pin9（或 pin10，都是 GND）
模块 VCC → 独立 3.3-5V 供电（勿接 J58 pin11！那是 3.3V VCC 但不建议从板取电）
```

## 如需重新配置某块模块

1. SET 接 GND **再上电**（AT 固定 9600）；或上电后接 SET（AT 走已配波特率）。
2. 发 AT+FU3 / AT+B115200 / AT+C001 或 AT+C006。
3. AT+RX 回读确认四项全对（B115200/RCxxx/+20dBm/FU3）。
4. 拔 SET → 透传。
