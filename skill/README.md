# Skill Package

## Overview
Reusable tools developed during this project that work on any FPGA board.

## Contents (to be added W5)

### puf_eval.py
One-click PUF evaluation: uniqueness, reliability, NIST randomness tests.

### mavlink_loopback.py
Radio link quality test: round-trip latency, packet loss, throughput.

### build_automation
Parameterized Vivado Tcl build scripts for any 7-series design.
